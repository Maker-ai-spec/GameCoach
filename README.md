# ♔ GameCoach

**Personal chess coach for Windows**

GameCoach helps chess players understand their mistakes, find better moves, and improve through personalized training based on their own games.

## ✨ Features

- ♟️ Analyze chess games with Stockfish
- 🧠 Understand mistakes and better moves
- 🎯 Train positions from your own games
- 🔁 Replay Trainer
- 🧩 Personal Puzzle Lab
- 📚 Opening Repertoire
- 👑 Endgame Coach
- 📊 Player Intelligence
- 📈 Progress tracking
- 🤖 Adaptive Coach
- ⚔️ Play against Stockfish
- 🌐 Import Chess.com games
- 🎨 Multiple board themes and piece styles

## 🚀 Download

The latest Windows installer is available from the **Releases** section of this repository.

Download:

`GameCoachSetup_1_0.exe`

Run the installer and launch GameCoach.

> Windows SmartScreen may display a warning because the current installer is not digitally signed.
